# Contributing
This document is a set of guidelines for contributing to this repository.

## Code of Conduct
This project follows a [Code of Conduct][code_of_conduct] in order to ensure an open and welcoming environment.

## How to submit changes
1. [**Clone**][clone] the project to your own machine.
    ```sh
    git clone https://github.com/path/to/repository
    ```
1. If you cloned a while ago, get the **latest changes**.
    ```sh
    git pull
    ```
1. Create a new **topic branch** to contain your feature, change, or fix.
    ```sh
    git checkout -b <topic-branch-name>
    ```
1. **Commit** changes to your own branch.
    ```sh
    git add *
    git commit -m 'Add some feature'
    ```
1. [**Push**][push] your topic branch up to your remote repository.
    ```sh
    git push origin <topic-branch-name>
    ```
1. Open a [**Pull Request**][pull] with a clear title and description so that we can review your changes.

Thanks for your interest in contributing to this repository.
